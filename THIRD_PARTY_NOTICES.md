## langfuse-python

Portions of this repository contain, or are derived from, source code of
[`langfuse/langfuse-python`](https://github.com/langfuse/langfuse-python),
used here as the benchmark's target repository. Specifically:

- `defects/*.patch` — unified diffs whose context and modified lines are
  langfuse-python source.
- `data/prs/*/diff.patch` — verbatim diffs of merged langfuse-python pull
  requests, retrieved from the public GitHub API.
- `data/runs/**` and `data/demo_runs/**` — model responses whose prompts
  embedded the diffs above.

No modification of langfuse-python is distributed here for use as a library.
The injected-defect patches are deliberately incorrect code, authored solely as
benchmark fixtures, and must not be applied to a production installation.

## Model outputs

Files under `data/runs/` and `data/demo_runs/` are responses generated by
third-party language models (Anthropic, OpenAI, and Google models, routed via
OpenRouter). They are published as experimental records. Provider terms
generally assign output rights to the API customer while restricting use of
outputs to train competing models; consult the relevant provider's terms before
reusing this data for model training.
